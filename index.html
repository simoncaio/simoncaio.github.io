Secure Access - Script Inspection Demo

Esta página foi criada para demonstrar inspeção e bloqueio de scripts por soluções SWG/CASB como o Cisco Secure Access.

A página tenta carregar um script externo considerado suspeito.

Status esperado:
  • Se o script for bloqueado → a solução SWG identificou e bloqueou o conteúdo.
  • Se o script carregar → aparecerá um alerta JavaScript.

Script externo carregado

URL do script:

https://secure.eicar.org/eicar.com

O que demonstrar no Secure Access

  • Bloqueio do domínio do script externo
  • Logs de acesso HTTP/HTTPS
  • TLS Inspection
  • Detecção de conteúdo ativo/script
  • Categoria/reputação do domínio
  • Eventos SWG relacionados ao bloqueio

Resultado esperado

✔ Caso o Secure Access esteja funcionando corretamente, o domínio/script externo deverá ser bloqueado.
